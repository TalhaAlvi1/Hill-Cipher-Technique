# Objective
To implement the Hill Cipher algorithm in C++ for encrypting a message using matrix-based substitution. This algorithm demonstrates the use of linear algebra in cryptography by encoding plaintext into ciphertext using matrix multiplication.
# Algorithm

1.Define a key matrix of size n×nn \times nn×n (where nnn is the size of the block).

2.Convert plaintext into numerical form (e.g., A = 0, B = 1, ..., Z = 25).

3.Divide plaintext into blocks of size nnn. If the length is not a multiple of nnn, pad the plaintext with additional characters like 'X'.

4.Perform matrix multiplication between the key matrix and each plaintext block.

5.Compute the result modulo 26 to ensure the result maps to a valid character.

6.Convert the resulting numerical values back to letters to form the ciphertext.

# Explanation
**1.Key Matrix:** A predefined matrix of size 2×22 \times 22×2 is used to encrypt blocks of plaintext.

**2.Plaintext:** User inputs a string that is converted into numbers (A = 0, ..., Z = 25).

**3.Padding:** Ensures the plaintext length is a multiple of the key matrix size.

**4.Encryption:** Each block of plaintext is multiplied by the key matrix. The results are taken modulo 26 to stay within the alphabet range.

**5.Output:** Ciphertext is generated by converting numbers back to characters.
